# 小葱工作台

一个本地记账 + 每日打卡网页。页面负责展示和录入，数据直接保存在项目目录下的 `data.json`。

- **每日记账**：记录每天的花销，按日期、分类查看明细，还有月度分类统计
- **每日打卡**：维护每天/每周/指定日期需要完成的小任务，按日历打卡，统计连续打卡天数和全勤天数
- **今日复盘**：任务列表下面的输入框，相当于每天默认的一项任务，写下当天的感受和收获，按日期自动保存

## 启动

双击 `start.command`，浏览器会自动打开：

```text
http://127.0.0.1:8765
```

也可以在终端里运行：

```bash
cd "/Users/bicongcong/Documents/小工具/accounting"
python3 server.py
```

关闭运行服务的终端窗口即可停止。

> 不要直接双击 `index.html`。直接打开文件时，浏览器没有权限写入本地 JSON 文件，页面会提示先启动本地服务。

## 每日打卡

左侧边栏可以在「每日记账」和「每日打卡」之间切换。

打卡页面左侧是任务管理：

- 点击 **添加任务** 会打开弹窗，填写任务名称并选择重复方式：
  - **每天**：每天都打卡
  - **每周**：选择一周中的某几天（可多选，如周一、周三、周五）
  - **每月**：选择每月几号（1-31 号可多选，如 1 号、15 号）
  - **不重复**：只在指定日期需要打卡一次
- 任务列表只显示 **今天需要打卡的任务**，当天不需要的不会出现
- 列表右上角的 **全部任务** 可以看到所有任务（包括今天不需要打卡的），并在这里删除
- 删除每周 / 每月的重复任务时，会问你是 **只删除今天**（跳过今天，之后的计划照常）还是 **删除全部**（任务和历史打卡记录一起删除）；每天和不重复的任务直接删除

右侧是打卡日历：点击某一天查看当天情况。顶部会显示本月打卡次数、全勤天数和连续打卡天数。

任务列表下面是 **今日复盘**：一个每天默认存在的大输入框（不需要手动添加）。输入后停顿片刻会自动保存到 `data.json`，点击日历上的其他日期时会显示那一天的复盘内容，标题也会跟着变成「X月X日复盘」。

右下角的当日明细会列出那天的任务和 **已完成 / 未完成** 状态，并在下面显示当天的复盘内容。

## 数据文件

所有记录都保存在：

```text
/Users/bicongcong/Documents/小工具/accounting/data.json
```

每次新增、删除或打卡都会实时写入。数据结构：

```json
{
  "version": 1,
  "records": [
    {
      "id": "唯一ID",
      "date": "2026-11-02",
      "item": "午餐",
      "amount": 32.5,
      "category": "餐饮",
      "createdAt": 1793625510798
    }
  ],
  "tasks": [
    {
      "id": "唯一ID",
      "name": "背单词",
      "schedule": "daily | weekly | monthly | once",
      "weekdays": [1, 3, 5],
      "days": [1, 15],
      "date": "2026-11-25",
      "skips": ["2026-11-25"],
      "createdAt": 1793625510798
    }
  ],
  "checkins": [
    {
      "id": "唯一ID",
      "taskId": "对应任务的 id",
      "date": "2026-11-24",
      "createdAt": 1793625510798
    }
  ],
  "reflections": {
    "2026-11-25": "今天的复盘内容"
  }
}
```

**记账 records：**

- `date`：日期，格式为 `YYYY-MM-DD`
- `item`：消费项目
- `amount`：金额，单位为元
- `category`：分类
- `createdAt`：记录创建时间的时间戳

**打卡 tasks：**

- `name`：任务名称
- `schedule`：重复方式，`daily`（每天）、`weekly`（每周）、`monthly`（每月）、`once`（不重复）
- `weekdays`：按周时生效，需要打卡的星期几，`0` 是周日，`1-6` 是周一到周六
- `days`：按月时生效，每月需要打卡的几号（1-31）
- `date`：不重复时生效，唯一需要打卡的日期，格式为 `YYYY-MM-DD`
- `skips`：被「只删除今天」跳过的日期列表，这些日期不再需要打卡

**打卡 checkins：**

- `taskId`：对应任务的 id
- `date`：打卡日期，格式为 `YYYY-MM-DD`

**复盘 reflections：**

- 键是日期（`YYYY-MM-DD`），值是对应那天的复盘文字
- 日期为空或文字清空时，这条记录会自动删除

## 备份

页面右上角的 **下载备份** 会下载一份带日期的 JSON 备份，包含记账记录、任务和打卡记录。

也可以直接复制 `data.json` 文件保存到别处。恢复时使用 **导入**，注意导入会覆盖当前 `data.json` 中的记录。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面界面和交互（记账 + 打卡） |
| `server.py` | 本地服务，负责读写 `data.json` |
| `data.json` | 记账、任务和打卡数据（不提交到 git） |
| `start.command` | macOS 双击启动脚本 |
